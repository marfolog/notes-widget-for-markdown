# v1.5.0

- An empty widget says why, and finds notes that sit in subfolders (Pick a subfolder)
- Fast Note Target can be cleared, and the app can create its own Quick notes.md for it
- Git sync tells you when your git client can no longer reach the remote

Two builds: `foss` has no `INTERNET` permission, `play` adds analytics and crash reporting that are
off until you agree, plus the optional feedback form. Take `foss` unless you want to send reports.
